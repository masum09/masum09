# Tera-Link style mini site

I couldn't clone `https://github.com/bbrbd4/Tera-Link.git` in this environment due a GitHub network restriction (HTTP 403).

So I created a lightweight **Tera-Link-style starter** that you can run directly.

## Files
- `index.html` – page structure
- `styles.css` – styling
- `app.js` – simple state management with `localStorage`

## Run
Open `index.html` in a browser.
